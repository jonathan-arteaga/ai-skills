Factual reference, with no upstream text copied:

- [21st.dev](https://21st.dev/community/components) for the public category
  taxonomy and URL slugs, observed on 2026-09-27. Category names and links
  are recorded as facts; no component code, descriptions, or site copy were
  copied.
- 21st.dev's own agent skills (`21st-ui-build`, `21st-ui-explore`), listed at
  `https://21st.dev/.well-known/skills/index.json`, were reviewed as
  neighbours and not copied.

This skill is a distinct workflow for non-designers. It turns a site type into
a plain-English shopping list of 21st.dev categories, collects the user's own
picks through a paste-back template, and consolidates them into a brief before
handing off to design-md, design-pages, and the stack's build skill. It needs
no 21st.dev account, API key, CLI, or MCP.
