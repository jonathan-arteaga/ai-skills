# 21st.dev categories

Checked 2026-09-27 from https://21st.dev/community/components. Counts change daily and are left out. If a link 404s or the sidebar no longer matches, re-read the live page and say this file is stale.

Every category link opens a browsable grid. Append `.md` to a category link for a text list of its components, or to a single component's URL for its author, license, npm dependencies, and live-preview link. The `.md` page does not include the code; installing it needs a 21st API key, which this skill does not use.
