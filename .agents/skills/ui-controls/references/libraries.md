# External lookups

Use these when the naming map is not enough and you need a real-system example. Read, do not copy.

## Component catalogs

- [The Component Gallery](https://component.gallery/components/) — same primitive across design systems, with aliases. Start here for Badge, Label, Header, Heading, Select, Table.
- [02UI components](https://02ui.com/components/) — when to use this control versus the neighbor.
- [UX Components](https://www.ux-components.com/) — what the control is and when not to reach for it.

## Foundations

- [Material 3 elevation](https://m3.material.io/styles/elevation/overview) — layer model for depth.
- [Shopify Polaris components](https://polaris.shopify.com/components) — admin usage rules for Badge, Index table, Filters.

## Do not vendor

Do not paste Component Gallery pages, 02UI pages, Polaris, Material, Emil Kowalski skills, or third-party `components.md` files into this repository. Point at the URL. Keep this skill's rules short and owned.
